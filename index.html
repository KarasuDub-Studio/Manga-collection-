Пошук у Google

Щоб застосунок брав дані про видання напряму з пошуку Google (а не лише з Google Books), потрібен безкоштовний ключ Google Custom Search API — сайти напряму заборонили автоматичне зчитування сторінки видачі, це офіційна заміна. Займає 2 хвилини:

  1. Відкрийте programmablesearchengine.google.com ↗, створіть пошукову систему, увімкніть «Пошук у всьому інтернеті» і скопіюйте Search engine ID.
  2. Відкрийте console.cloud.google.com ↗, увімкніть Custom Search API та створіть API-ключ (Credentials → Create credentials → API key).
  3. Вставте обидва значення нижче.

Без налаштування ключа пошук усе одно працює через Google Books і Open Library — просто охоплення українських видань там менше. Ключ зберігається лише у вашій колекції на цьому пристрої.
